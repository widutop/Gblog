# Gblog 安装手册

> 面向：第一次部署 Gblog 的人。跟着做一遍即可跑起来。
> 版本：GBLOG_CORE_VERSION 1.4.0 · 2026-11

---

## 1. 环境要求

| 项 | 要求 |
|---|---|
| PHP | **8.0 及以上**（代码用了 `str_starts_with` 等 8.0 语法） |
| 数据库 | MySQL 5.7+ / MySQL 8，或 SQLite 3（PHP 需开启 `pdo_sqlite`） |
| Web 服务器 | nginx / Apache / IIS 均可，需支持 URL 重写（伪静态） |
| PHP 扩展 | `pdo`、`pdo_mysql`（或 `pdo_sqlite`）、`mbstring`、`gd`（图片处理）、`fileinfo` |

> 常见 phpstudy / 宝塔 / 虚拟主机面板都满足。无需 Composer，无第三方 PHP 依赖。

---

## 2. 三步安装

### 第 1 步：上传源码

把本仓库的文件上传到网站根目录（能通过 `http://你的域名/` 访问到 `index.php` 的那一层）。

### 第 2 步：给目录写权限

确保以下目录 **Web 服务器用户可写**（Linux 上通常 `chmod 755` 或 `777`）：

```
usr/data/          # 数据库配置、SQLite 库、备份
usr/uploads/       # 上传的图片/音频/附件
```

> 这两个目录已带 `.htaccess` / `web.config` 防护，禁止 HTTP 直访，不用担心放配置在 `usr/data/` 不安全。

### 第 3 步：运行安装向导

浏览器打开：

```
http://你的域名/install.php
```

按提示填写数据库信息（数据库名、用户名、密码、主机），设置管理员账号，点「安装」。

安装完成后向导会提示删除 `install.php`。**建议照做**（`install/` 目录可留可删，删掉更安全且不影响运行）。

---

## 3. 安装后必做：配置伪静态

Gblog 支持漂亮 URL（如 `/post/101.html`）。不配伪静态会导致**内页全部 404**（首页正常）。

根据你用的 Web 服务器选一种：

### nginx

把仓库根目录 `nginx.htaccess` 的内容，加进站点的 nginx 配置 `server { }` 块里。**注意**：`include` 指令要放在 `server` 级，不要放 `location /` 里面（会被 `location ~ \.php` 压过，导致 `/usr/data/*` 被公网访问）。

nginx 配置**不要写 `{n}` 量词**（部分老版本 nginx 不支持）。

### Apache

仓库根目录有 `.htaccess`，只要 Apache 开启了 `mod_rewrite` 并允许 `.htaccess` 覆盖（`AllowOverride All`）就自动生效。虚拟主机若不支持 `.htaccess`，把 `install/apache-htaccess.txt` 的内容贴进虚拟主机配置。

### IIS

用 `web.config` 的 URL Rewrite 规则（安装器会在 `usr/data/` 写入防护用的 `web.config`；伪静态规则需自行按下面「URL 形态」在 IIS 里配置）。

### URL 形态

伪静态支持三种形态，后台「功能开关 → 伪静态」里可切换或关闭：

| 形态 | 示例 |
|---|---|
| 形态 1 | `/post/101.html`（数字 ID） |
| 形态 2 | `/post/20261114101.html`（带日期的 ID） |
| 形态 3 | `/post-101.html` |

栏目首页用栏目 slug：`/栏目slug.html`；内容页前缀按栏目类型自动生成（文章 `post`、歌曲 `music`、软件 `soft`、图库 `image`、小说 `novel`）。

关闭伪静态时退化为 `?do=` 查询串形式，任何服务器都能用。

## 4. 登录后台

```
http://你的域名/admin/
```

用安装时设置的管理员账号登录。后台可以：新建栏目、发布文章/歌曲/软件、管理分类标签、选主题与版式、备份数据。

后台首次进入建议先改密码（「账号 → 修改密码」）。

---

## 5. 升级与迁移

- **覆盖升级**：下载新版源码，覆盖到站点根。`config.php`（在 `usr/data/`）、上传目录、备份目录都属于用户数据，**不会被覆盖**（升级包不含这些）。
- **数据库迁移**：核心启动时会检测 schema 版本并自动执行增量迁移（`gblog_migrate()`），无需手工导库。
- **换域名/换主机**：整站目录打包搬走，改 `usr/data/config.php` 里的站点信息即可；数据库一起迁移。

## 6. 常见问题

**Q：首页能开，点任何内页都 404？**
伪静态没配好。按第 3 步重新配置，或到后台关闭伪静态用 `?do=` 模式验证。

**Q：整页没样式、一堆纯文本？**
资源路径解析错了。确认没有在页面里用 `<base href>`（它会破坏锚点和路径）；Gblog 全站资源用根绝对路径，正常不需要额外设置。若站点装在子目录，确认 `gblog_web_base()` 识别到正确基址。

**Q：后台打不开 / 空白？**
先看 PHP 错误日志。常见是 PHP 版本低于 8.0，或缺少 `pdo_mysql` / `pdo_sqlite` 扩展。

**Q：忘记管理员密码？**
进数据库 `users` 表，把对应账号的 `password_hash` 字段用 `password_hash('新密码', PASSWORD_DEFAULT)` 生成的值替换即可。

**Q：装完想删 `install/` 目录，有影响吗？**
基本没有。运行时唯一引用是迁移时补建外键用的 `install/mysql_constraints.sql`，删掉后 `is_file()` 检查失败会静默跳过，外键建表时已建好，不影响任何页面。只是失去「重装」能力。若安装时曾提示外键因权限未创建，删前把该 SQL 留档一份。
