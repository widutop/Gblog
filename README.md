# Gblog

简洁优雅的国产 PHP 博客系统。单用户/多栏目，支持文章、音乐、软件、图库、小说多种内容形态，富文本 + Markdown 双编辑器，主题可自由定制。

> GBLOG_CORE_VERSION 1.4.0 · schema v12 · 2026-11

---

## 特性

- **多内容形态**：文章、音乐（歌词打点）、软件（下载/金币）、图库、小说（章节），统一 ID 管理
- **栏目制**：自定义栏目（site）+ 分类 + 标签，栏目可独立设置首页形态与版式
- **双编辑器**：wangEditor 富文本 + Markdown 模式，内容存库前统一净化；老文章自动识别格式
- **版式系统**：按栏目类型推荐版式，后台可选版式，主题模板按文件名识别（不用改代码）
- **主题继承**：激活主题 + 父主题两层链，做子主题只覆盖要改的文件
- **伪静态**：三种 URL 形态可切换，支持 nginx / Apache / IIS
- **备份恢复**：一键备份数据库与文件，支持异地备份认领
- **零 Composer 依赖**：原生 PHP 8.0+，MySQL 或 SQLite 都能跑

## 快速开始

```bash
# 1. 把源码放到网站根目录
# 2. 给 usr/data/ 和 usr/uploads/ 写权限
# 3. 浏览器打开 install.php 按提示填写数据库、设置管理员
http://你的域名/install.php
# 4. 按你的服务器配置伪静态（见安装手册），登录后台开始写作
http://你的域名/admin/
```

详细步骤见 **[安装手册](docs/安装手册.md)**。

## 目录结构

```
.
├── index.php          前台入口
├── admin/             后台管理（发布、栏目、主题、备份…）
├── app/               前台控制器（按栏目分目录）
├── core/              核心：bootstrap / data / route / render / ext / auth / lib
├── install/           安装器与建表 SQL
├── usr/
│   ├── themes/        主题（default 为官方参考实现）
│   ├── plugins/       插件
│   ├── uploads/       用户上传（不入库，可清空）
│   └── data/          配置、SQLite 库、备份（用户数据，升级不覆盖）
├── nginx.htaccess     nginx 伪静态规则
└── .htaccess          Apache 伪静态与防护规则
```

## 技术栈

PHP 8.0+ · MySQL 8 / SQLite 3 · 原生 JavaScript（无前端构建）· nginx / Apache / IIS
